# Commit Complete Changes

For a request that changes this repository, make one commit after the coherent change is complete and checked. Keep related follow-up fixes in that commit when they are part of the same unfinished request. Do not commit partial work or create a commit for a read-only discussion.

Before committing, inspect the diff and working tree, run checks appropriate to the change, and stage only files that belong to the completed request. Preserve unrelated work already in the tree. Follow the repository's commit message convention and verify the new commit and remaining working tree status.
